Data Flow

1
User selects a filter
FilterBar.vue dispatches a change to the useFilters() composable. All four filter refs (period, location, category, status) are module-level singletons shared across every view.
FilterBar.vue useFilters.js
2
View watches filter changes
Each page-level view uses watch([selectedPeriod, selectedLocation, ...], loadData). When any filter changes, the data-loading function fires automatically.
Dashboard.vue Inventory.vue Orders.vue watch()
3
api.js builds the HTTP request
getCurrentFilters() maps UI state to API params (e.g. selectedLocation → warehouse). Non-"all" values are appended to URLSearchParams and sent via axios GET.
api.js URLSearchParams axios
4
FastAPI filters in-memory data
apply_filters() sequences through warehouse → category → status. filter_by_month() handles direct month strings (2025-01) and quarter aliases (Q1-2025). Pydantic validates the response shape.
apply_filters() filter_by_month() Pydantic
5
Vue renders via computed properties
Raw API data lands in a ref([]). Computed properties derive sorted, formatted, or further-filtered views from that ref. Templates auto-update; no manual DOM manipulation required.
ref() computed() Reactivity
